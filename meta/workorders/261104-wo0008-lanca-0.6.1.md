
**5d — Release `v0.6.1`** (texto em ingles, publico):

```
gh release create v0.6.1 --repo joaolucas-nds/framematch --title "FrameMatch 0.6.1" --notes "FrameMatch fills a whole catalog of Figma frames from a CSV and a folder of images, matched by layer name.

What's in this version (0.6.0 + 0.6.1):
- Ready for the Figma Community: dynamic page loading, no network access.
- User interface in English.
- Friendlier error messages; a warning if the template cannot be deleted.
- Text layers in the generated frames keep their names (Name, Brand...) instead of being renamed to the filled-in text.
- README with screenshots of every step and an Auto Layout tip.

See the README for the full guide."
```

Confira com `gh release view v0.6.1 --repo joaolucas-nds/framematch` e `gh repo view joaolucas-nds/framematch` (descricao e topicos) e cole as saidas no relatorio.
